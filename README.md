# 🛍️ MEG Giyim PRO v7.5 - Masaüstü E-Ticaret Yönetim Sistemi

Bu proje, Python ve **CustomTkinter** kullanılarak geliştirilmiş, modern görünümlü bir masaüstü alışveriş uygulamasıdır. SQLite veritabanı entegrasyonu sayesinde kullanıcılar, siparişler ve stok durumu anlık olarak yönetilmektedir.



## ✨ Öne Çıkan Özellikler

* **Misafir Modu:** Kullanıcılar giriş yapmadan vitrini gezebilir ve ürünleri inceleyebilir.
* **Gelişmiş Üyelik Sistemi:** Kullanıcı kaydı, şifreli giriş ve yetkilendirme (Admin/User) özellikleri.
* **Admin Paneli:** Stok yönetimi ve yeni ürün ekleme işlemlerini uygulama üzerinden yapabilme.
* **Stok Takibi:** Satın alma sonrası otomatik stok düşüşü ve "Tükendi" durumu yönetimi.
* **Beden Seçimi:** Sipariş sırasında ürünlere özel beden (S, M, L, XL) belirleme.
* **Favoriler & Sipariş Geçmişi:** Kullanıcıya özel saklanan kişisel listeler.
* **Modern Arayüz:** Tamamen karanlık mod (Dark Mode) uyumlu, şık ve kullanıcı dostu tasarım.

## 🛠️ Teknik Altyapı

* **Dil:** Python 3.x
* **Arayüz Kitaplığı:** `customtkinter` (Modern Tkinter sarmalayıcısı)
* **Veritabanı:** `sqlite3` (Yerel ilişkisel veritabanı)
* **Tasarım:** Sürdürülebilir Nesne Yönelimli Programlama (OOP) yapısı.



## 🚀 Kurulum

1.  Gerekli kütüphaneleri bilgisayarınıza yükleyin:
    ```bash
    pip install customtkinter
    ```
2.  Projeyi klonlayın veya dosyaları indirin.
3.  Uygulamayı başlatın:
    ```bash
    python app.py
    ```

## 🔑 Kullanım İpuçları

* **Giriş:** Ürünleri görmek için giriş zorunlu değildir.
* **Satın Alma:** Sepete ekleme ve satın alma işlemleri için kayıt olmanız gerekmektedir.
* **Admin Erişimi:** Yönetici paneline erişmek için:
    * **Kullanıcı Adı:** `admin`
    * **Şifre:** `1234`
